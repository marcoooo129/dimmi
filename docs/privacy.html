Privacy, plainly stated

隐私说明

这是 dimmi v0.1.0 Beta 的透明数据说明。正式发布前会根据最终签名、存储方案和 GitHub 仓库信息更新生效日期。

一句话版本

dimmi 没有自建翻译服务器，也没有遥测或广告 SDK。你的翻译请求由这台 Mac 直接发送给你选择的模型服务商或自定义端点；翻译历史和解析缓存在本机。

dimmi 会处理哪些数据

你复制或选中的文字

自动翻译开启时，符合最少/最多字符条件的新复制文本，或你在划词模式下主动选中的文本，会作为翻译请求发送给所选模型。

译文与表达解析

开启表达解析后，原文与主译文会用于向同一模型服务发起额外请求，以生成短语拆解、用法说明和例句。

API 配置

服务商、模型 ID、Base URL 与 API Key 保存在本机应用偏好中。当前 Beta 版尚未使用 macOS Keychain 加密 API Key，请勿在共享 macOS 账户中保存高敏感度密钥。

数据保存在哪里

  • 翻译历史：保存在本机 SwiftData 数据库。
  • 表达解析缓存：保存在 ~/Library/Application Support/dimmi/notes.json，其中可能包含原文与译文。
  • 设置与 API 配置：保存在当前 macOS 用户的应用偏好中。
  • dimmi 当前没有账户系统、云同步或跨设备上传。

清空“历史记录”只会清除历史数据库；解析缓存需要在“翻译设置 → 缓存管理”中单独清理。

数据会发送给谁

只有你选择的模型服务商或自定义端点会接收翻译请求。对应服务商如何保存和使用请求数据，取决于你与该服务商之间的条款和隐私政策。

自定义端点可以是本机服务、企业网关或互联网地址。建议优先使用 HTTPS，或仅使用你信任的本地地址。

系统权限

辅助功能

仅在你主动选择“划词模式”时使用，用于监听鼠标选择完成并读取选中文字。默认“复制模式”不需要该权限。

剪贴板

复制模式会在本机检测剪贴板是否出现新的文本。macOS 不会为普通剪贴板读取显示独立授权弹窗。

敏感内容提醒

自动复制翻译开启时，新复制且符合触发条件的文本可能被发送给所选模型。复制密码、访问令牌、私钥或其他敏感内容前，请先从菜单栏暂停自动翻译。

遥测与追踪

当前源码没有集成行为分析、广告追踪、用户画像或第三方崩溃上报服务。GitHub Pages 托管本介绍页时，访问日志与基础设施数据由 GitHub 按其隐私政策处理。

你的控制

  • 随时暂停自动翻译。
  • 在设置中切换回无需辅助功能权限的复制模式。
  • 在 macOS 系统设置中撤销辅助功能权限。
  • 删除单条历史、清空全部历史，并单独清除表达解析缓存。
  • 删除已保存的 API Key，或完全移除应用及其本机数据。
