Privacy, plainly stated

Privacy Policy

This is a transparent data statement for dimmi v0.1.0 Beta. The effective date will be updated upon official release based on final signatures, storage solutions, and GitHub repository info.

The TL;DR Version

dimmi has no self-hosted translation servers, nor telemetry or advertising SDKs. Your translation requests are sent directly from your Mac to your chosen model provider or custom endpoint. Translation history and analysis cache are kept strictly on your local device.

Data Processed by dimmi

Text You Copy or Select

When auto-translate is on, new copied text matching the character length conditions, or text you actively select in selection mode, will be sent as translation requests to your chosen model.

Translations & Phrase Analysis

When phrase analysis is enabled, the source text and main translation are used in an additional request to the same model provider to generate phrase breakdowns, usage context, and examples.

API Configurations

Provider selection, Model IDs, Base URLs, and API Keys are saved in local app preferences. The current Beta version does not yet encrypt API Keys via macOS Keychain. Please do not save highly sensitive keys on shared macOS accounts.

Where Data is Stored

  • Translation History: Stored in a local SwiftData database.
  • Phrase Analysis Cache: Stored in ~/Library/Application Support/dimmi/notes.json, which may contain source text and translations.
  • Settings & API Configurations: Stored in the current macOS user's app preferences.
  • dimmi currently has no account system, cloud sync, or cross-device uploads.

Clearing "History" only clears the history database; the analysis cache must be cleared separately in "Translation Settings → Cache Management".

Who Receives Your Data

Only your chosen model provider or custom endpoint receives the translation requests. How those providers store and use request data is governed by the terms and privacy policies between you and that provider.

Custom endpoints can be local services, corporate gateways, or internet URLs. It is recommended to use HTTPS, or use trusted local addresses only.

System Permissions

Accessibility

Used exclusively when you actively select "Selection Mode", to detect when a mouse drag is completed and to read the selected text. The default "Copy Mode" does not require this permission.

Clipboard

Copy mode monitors the local clipboard for newly added text. macOS does not show separate authorization prompts for standard clipboard reading.

Sensitive Content Warning

When auto-translate on copy is enabled, newly copied text meeting the trigger conditions may be sent to the selected model. Before copying passwords, access tokens, private keys, or highly sensitive content, please pause auto-translation from the menu bar.

Telemetry & Tracking

The current source code integrates no behavioral analytics, ad tracking, user profiling, or third-party crash reporting services. When this landing page is hosted on GitHub Pages, access logs and infrastructure data are handled by GitHub according to its privacy policy.

Your Controls

  • Pause auto-translation at any time.
  • Switch back to Copy mode in settings to stop requiring Accessibility permissions.
  • Revoke Accessibility permissions in macOS System Settings.
  • Delete single history items, clear all history, and clear the analysis cache individually.
  • Delete saved API Keys, or completely uninstall the app and its local data.
