FAQ

开始之前，
你可能想知道。

dimmi 是免费的吗？

应用当前以 GitHub Beta 形式提供。翻译使用你自己的 API Key，模型费用由对应服务商收取。

不填写 API Key 能使用吗？

可以先体验本地示例结果和界面；真实翻译需要配置一个服务商 Key，或连接兼容的本地/自托管端点。

为什么首次打开会有安全提示？

当前 GitHub Beta 尚未使用 Developer ID 签名和 Apple 公证。请从项目的官方 Release 下载，并在 Finder 中右键应用选择“打开”。

划词模式为什么需要辅助功能权限？

该权限用于监听你完成的鼠标选区并读取选中文字。默认复制模式无需此权限；你也可以随时在系统设置中撤销。

复制密码时会发生什么？

自动复制翻译开启时，符合字符条件的新文本可能被发送给所选模型。复制密码、令牌或私密内容前，请先暂停自动翻译。
